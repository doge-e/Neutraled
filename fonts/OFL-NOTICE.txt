一、一句话
----------------------------------------------------------------
Neutraled 自带字体包里的全部字形，都是用 **SIL Open Font License 1.1（OFL-1.1）** 授权的
开源字体（Google Noto 家族）**离屏渲染**出来的位图。

我们不重新分发字体文件本身（包内没有任何 .ttf / .otf / .ttc），只分发**位图页 + 字形坐标表**；
每张位图页对应的源字体、版本、上游文件与版权行见第二节；OFL 全文随包放在 fonts\ofl\ 下（第三节）；
OFL 要求的版权与许可随附、保留字体名、不得单独售卖等条款，我们的做法见第四节。

### 版本沿革（为什么从 6 页变 4 页）

- 2026-09-29 首版 OFL 包：**4936 字形 / 6 页**（o1 SC 4679、o2 SC 补字 19、o3 JP 0、o4 KR 3、o5 Symbols 2 232、o6 Emoji 3）。
- 真机发现**全角标点整体错位一码位**（`（`显示成`）`、`，`显示成`－`），仅出现在用内置字体包的两个面（F2 控制台、根章节选择器）；
  根因是平均切片。修 `builder/CjkFont.cs`（全宽组逐字渲染 + 统一步进 + `adv = max(shift, w) + 1`）后用修好的 builder **全量重渲**。
- 重渲口径：字符表 5666 个候选 → 按 SC → SC 补 → JP → KR → Symbols 2 → Emoji 顺序逐字体渲染（每轮只剩「前面没覆盖的字」）→ 合并去重 → **4974 字形 / 4 页**。
- 与旧包相比：**新增 48 个字形**（emoji 区符号 U+21A9 ↪ ↪ ♈…⛽，以及 U+3000 全角空格）；**丢弃 10 个 Unicode 未分配码位**
  （U+3040 / U+3097 / U+FF00 / U+FFA0 / U+FFC8 / U+FFD0 / U+FFD8 / U+FFDD / U+FFDE / U+FFE7）——
  它们在源字体里本来就是空白格，旧包把空白格当字形留着；丢弃属正确清理。
- 机器可读的记录：`E:/aiwork/out/Neutraled2/_feat/rerender-ofl-report.json`（页 → 来源 pass → 字节 + 未覆盖字符）；渲染日志 `_feat/rerender-ofl.log`。
- 旧版的 7 张专有页（`_page`、`_ja_sheet0`、`_latin_sheet0`、`_scripts_sheet0`、`_sym_sheet0`、`_wave_sheet0`、`_ko_sheet0`）在本目录中已不存在。

四、我们的合规做法
----------------------------------------------------------------
1. **不重新分发字体文件**：包内没有 .ttf / .otf / .ttc，只有渲染后的位图页与坐标表。
2. **保留版权与许可**：本 NOTICE 与第三节的 5 份 OFL 全文随包分发（OFL 1.1 要求版权声明与许可随字体或其衍生品传递）。
3. **不使用保留字体名**：OFL 的 "Reserved Font Name" 条款要求改名；Neutraled 既不把字体叫 "Source"/"Noto"，
   也不把字体包当成字体产品对外发布 —— 游戏内资源名是 「ntl_font_cjk」，文件名叫 「ntl_font_cjk_o1..o4.png」。
4. **不单独售卖**：这些位图不单独售卖，只作为 Neutraled（免费 mod 管理器）的一部分随包。
5. **可追溯**：第二节给了本地 TTF 的 SHA-256 与上游路径，任何人可按第五节重新生成并比对。
6. **字体名不用于背书**：Neutraled 与 Google / Adobe / Noto 项目**没有**隶属或背书关系。


五、重新生成（可复现流程）
----------------------------------------------------------------
前提：.NET 9（从源码构建）或发布包自带的 install\ntl-builder.exe；字符表来自"产物真正会用到的文本"
（与部署期内容自检同一口径，见 docs/MANAGE.md 的字体补全一节）。

  # 2) 逐字体渲染位图页（示例：Noto Sans SC；其它字体同理换 --ttf 与包名）
  ntl-builder.exe --make-cjk-font <输出目录> --ttf <NotoSansSC-VF.ttf> --charset list --chars <字符表文件> --font-name ntl_font_cjk

  #    → 输出 <包名>.json + <包名>_sheetN.png（本轮每个包都只有一张 sheet0）
  #    渲染期有**墨迹门禁**：全透明（画不出来）的字形会被丢弃，不会进包

  # 3) 合并：把各包的字形记录并入 Neutraled\fonts\ntl_font_cjk.json
  #    - Page 置空 → 多 sheet 模式；每张 sheet 拷到 fonts\ 下并改名 ntl_font_cjk_oN.png
  #    - 合并语义：后并入的包可顶替前面包生成的字形，**已有的汉字/ASCII 基底字形永不覆盖**（只增不改）
  #    - 注意：合并用的是一次性脚本（未随包保留）；可直接参考骨架
  #      E:/aiwork/out/Neutraled2/_feat/rerender-ofl.mjs（2026-09-30 全量重渲：pass 顺序 SC → SC 补 → JP → KR → Symbols 2 → Emoji，含墨迹门禁与合并去重）、
  #      merge-supp.mjs（补字合并）与 merge-fonts.mjs（多包合并，旧管线）

  # 4) 复核
  node E:/aiwork/out/Neutraled2/_feat/font-audit.mjs        # 缺字 / 空白格门禁（退出码 1 = 有缺口）
  ntl-builder.exe --font-probe chapter4_windows\data.win   # 字形数与字形表自检（逆序对应应为 0）


六、注意事项与已知局限
----------------------------------------------------------------
* 位图页是按**实际用到的字符集**渲染的，不是字体的全字库；**没有渲染到的字符在游戏里仍会空白**
  （不是方框、不是报错）—— 见 release-docs/KNOWN-LIMITATIONS.md 的 L11 / L25。
  2026-09-30 重渲口径：字符表 5666 个候选里有 **692 个**在 5 款字体中全部渲染不出（多为西里尔/希腊扩展、控制图形等极少用到的码位），
  它们不进包（墨迹门禁丢弃），在游戏里仍是空白；**丢弃 10 个 Unicode 未分配码位**的说明见第二节「版本沿革」。
* 上游是可变字体（wght 轴），本包按 **EmSize=12** 静态渲染，与游戏像素风格对齐；放大时不做重采样。
* Noto Sans JP 本轮**没有产出位图页**（轮到它时已无待补字符），见第二节「未产出位图页的字体」。
* 换字体/加语言时**不要**只改 JSON：位图页与坐标表必须成套生成，否则会出现空格或错位。
* 本文件只覆盖**字体包**的许可。Neutraled 项目自身（代码、脚本、文档）采用 MIT 许可（2026-09-29 起；见仓库根 LICENSE 与 Neutraled/NOTICE），
  见 release-docs/KNOWN-LIMITATIONS.md 的「许可合规」一节。

七、部署期本机字形覆盖（Native override）
----------------------------------------------------------------
背景：Neutraled 自绘 UI（章节选择器、F2 控制台、toast）原先直接用游戏字体；2026-09-29 起字体包全量改为
OFL Noto 位图后，UI 文字观感与游戏明显不同（用户真机反馈「疑似又被换成微软雅黑」）。因此引入
**部署期本机字形覆盖**：随包仍是纯 OFL，注入时在本机用游戏自己的字形覆盖对应码位。

* **随包仍是纯 OFL**：仓库/发布包的 fonts\ 里只有第二节那 4 张 OFL 位图页与坐标表，
  **没有任何游戏字体位图或汉化字库位图**。本机覆盖只发生在**用户自己的机器上、部署（注入）时**，
  产物写在 <Neutraled>\.tmp\font-native\，**不回写 fonts\，也不进发布包**。
* **声明式、可审计**：规则在随包的 fonts\ntl_native_sources.json（只声明码位区间与来源种类）：
  * latin 区（0x20-0x7E、Latin-1/扩展 A-B、常用引号/省略号/欧元/箭头）……来源 game → base-mod；
  * cjk 区（2E80-9FFF、F900-FAFF、FE30-FE4F、FF00-FFEF）……来源 game → base-mod，MinGlyphs=500
    （目标里汉字不足 500 个就判定该来源不可用，整区退回 OFL）。
  * 来源 **game** = 正在注入的那份 data.win（就是这台机器上游戏真正会用的字体：本机 fnt_main 的
    ASCII 是 8bitoperator JVE，汉字来自本机已装的汉化包）；
  * 来源 **base-mod** = 已安装基线汉化包的 ref\data.win（Neutraled\mods\<mod>\[<作者>]\<章节|root>\ref\data.win），
    只在 game 缺字时使用。
* **缺字自动回退**：本机没有覆盖到的码位继续用 OFL 位图（默认行为即 2026-09-30 全量重渲版）。
  每次部署写出 <Neutraled>\.tmp\font-native\<scope>\_report\merge-report.json 与 ofl-fallback-list.txt
  （哪些字换了本机字形、哪些字仍用 OFL、哪些字两边都没有）。任何一步失败都只记警告并**自动退回纯 OFL 包**，不会让部署失败。
* **许可证说明**：本机覆盖取用的位图来自由**用户自己安装/拥有**的游戏与汉化包（8bitoperator JVE 属
  DELTARUNE / Toby Fox；汉字位图属用户所装汉化包的作者）。Neutraled **不重新分发**这些位图，
  只在用户本机做与游戏同源的本地渲染，因此**不改变发布包的 OFL-clean 结论**。
  用户未安装汉化包时，汉字区自动回落到 OFL Noto（第二、三节），行为与旧版一致。
* **复核方式（逐像素断言）**：node E:/aiwork/out/Neutraled2/_feat/_t26/verify-csharp.mjs
  —— 新包 ASCII 0x20-0x7E / CJK 与游戏 fnt_main 逐像素一致；同时反证仓库 fonts\ 里没有任何本机页、
  没有字体二进制、OFL 字形与游戏不同源。完整报告：release-docs/FONT-PIXEL-REPORT.md。

八、2026-10-02 增补：非中文字形改用 Ark Pixel 12px 像素字体（OFL-1.1）
----------------------------------------------------------------
背景 : 用户报「那种看起来像带声调的字母（ä ü ß é ñ）还是微软雅黑」—— 这些码位不在游戏本机字体
       （8bitoperator JVE / 汉化像素汉字）里，部署期回退到本包的 Noto 位图，而 Noto 是平滑矢量字，
       混在像素风界面里像系统默认字体。

       箭头、数学与杂项符号）里 Ark Pixel 能提供的 **953** 个字形，替换为 Ark Pixel 12px 的像素位图；
       汉字段（U+2E80 以上，含汉字/假名/全角）**一个都没动**，仍是原来的 Noto 位图。
       只替换、不新增码位 ⇒ 字形总数仍为 4974。
